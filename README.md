# Divengine's Homebrew tap

Homebrew formulae of the [Divengine](https://github.com/divengine) projects, for macOS and Linux.

```bash
brew install divengine/tap/divide
```

`brew upgrade divide` updates it.

| Formula | Project |
|---|---|
| `divide` | [divide](https://github.com/divengine/divide): the Div template IDE that lives in your terminal |

The formulae are updated by each project's release workflow; changes made here by hand are overwritten by the next release.
